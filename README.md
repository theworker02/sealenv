# sealenv

Seal structured JSON env payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/sealenv/

## Install / run

```bash
git clone https://github.com/theworker02/sealenv.git
cd sealenv
node src/cli.js
node --test
```
